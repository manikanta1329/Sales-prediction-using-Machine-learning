# 📈 Sales Prediction using Machine Learning

## 📌 Project Overview
This project predicts product sales based on advertising budgets using Machine Learning techniques. The project uses Linear Regression to analyze the relationship between advertising platforms and sales performance.

Developed as part of the **Oasis Infobyte Data Science Internship**.

---

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## 📊 Dataset Information
The dataset contains advertising data for:

- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget
- Sales

---

## ⚙️ Project Workflow
1. Import Dataset
2. Data Preprocessing
3. Data Visualization
4. Split Training & Testing Data
5. Train Machine Learning Model
6. Predict Sales
7. Evaluate Model Accuracy

---

## 📈 Machine Learning Model
- Linear Regression

---

## ✅ Output
The model successfully predicts sales with good accuracy using advertising budget data.

---

## 📷 Visualization
The project includes graphical visualization between advertising budgets and sales.
